# Unity Learning

This repository contains my Unity learning projects, experiments, and development journal.

The main project in this repository is a first-person melee combat game built in Unity. The project focuses on learning and implementing core gameplay systems using C# and Unity.

## Current Project

### FPS Sword Game

A first-person melee combat game where the player can move around the environment, use a sword, block attacks, and fight enemies.

Current systems include:

* First-person player movement
* Mouse look
* Sprinting
* Jumping and gravity
* Head bob
* Sword attacks
* Sword hit detection
* Player health
* Enemy health
* Enemy AI
* Enemy detection and chasing
* Enemy attacks
* Enemy death state
* Player blocking

The project is still in development and new systems will be added over time.
